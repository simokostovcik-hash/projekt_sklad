COFFEE MINIMAL – OPRAVENÝ KOMPLETNÍ PROJEKT

OPRAVA:
- Jediný aktivní React frontend je frontend/ (dřívější kopie src/frontend/ byla odstraněna).
- frontend/src/App.jsx a App.css obsahují přepínač světlého/tmavého režimu vedle košíku.
- Backend Spring Boot a jeho administrační vzhled nebyly měněny.
- Zachováno API objednávek a dosavadní model databáze.

INSTALACE:
1. ZASTAV Spring Boot i Vite.
2. ZÁLOHUJ svoji aktuální složku data/ v původním projektu (historie objednávek).
3. Rozbal ZIP do nové složky. Nejdřív ověř, že funguje, nemaž hned starý projekt.
4. Pokud máš v původním projektu novější objednávky než v tomto ZIPu,
   zkopíruj aktuální složku data/ ze starého projektu do nového (při vypnutém backendu).
5. Otevři nový projekt v IntelliJ a spusť Spring Boot.
6. V terminálu z KOŘENE projektu spusť: cd frontend
7. Pak: npm install
8. Pak: npm run dev
9. Otevři adresu, kterou Vite vypíše, zpravidla http://localhost:5173/
10. Vpravo nahoře vedle Košíku je přepínač Tmavý / Světlý.

POZOR: ZIP obsahuje snímek databáze z nahraného projektu.
Nenahrazuj jím novější databázi bez zálohy!
